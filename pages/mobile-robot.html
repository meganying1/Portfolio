Mobile Robot

Developing an autonomous mobile robot to follow a curved path and avoid moving obstacles using infrared and ultrasonic sensors.

Overview

In a team of three, I helped develop an Arduino-based differential-drive robot that autonomously navigated an obstacle course. We integrated infrared and ultrasonic sensing with motor control to follow a curved line while detecting and stopping for moving obstacles.

We developed the control logic through repeated testing and tuning, adjusting sensor thresholds and motor commands to improve path tracking and recovery when the robot lost the line.

Sensor Integration

The robot used three infrared sensors to detect its position relative to the line and an ultrasonic sensor to identify obstacles ahead.

We characterized the infrared sensor response and selected thresholds that reliably distinguished the line from the surrounding surface. The ultrasonic sensor provided a separate distance measurement that stopped both motors when an obstacle entered the defined detection range.

Control Algorithm

We controlled the left and right motors independently based on the infrared sensor readings. When the center sensor detected the line, both motors ran at similar speeds. When either side sensor detected the line, we adjusted the relative motor speeds to steer the robot back toward the path, with larger deviations triggering stronger corrections.

The controller also tracked which side had most recently detected the line. If all three sensors temporarily lost the path, the robot used that previous state to determine which direction to search.

We tuned the sensor thresholds and motor-speed differences through repeated testing on the course, balancing fast recovery from large deviations with stable line following.

Results

The final robot successfully followed the curved course and avoided all moving obstacles, completing the challenge in 26 seconds and outperforming 75% of competing robots.
