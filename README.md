# [Megan Ying Portfolio](https://www.meganying.com/)

A compact portfolio of mechanical design, engineering experience, and publications.

The homepage shows a short introduction, three selected projects, the complete experience list, and two publications. Native expandable sections hold six more projects and the full skills list. All nine case studies retain their narratives, figures, and resources.

## Design system

Visual tokens live in [`css/tokens.css`](css/tokens.css), and shared components live in [`css/style.css`](css/style.css). See [`DESIGN.md`](DESIGN.md) for the palette, type scale, spacing, responsive rules, and component guidelines.

## Local preview

Run `python3 -m http.server 8766 --bind 127.0.0.1` from this directory, then open http://127.0.0.1:8766/.

## Stack

Static HTML, CSS, and a small JavaScript slide viewer. No build step or external fonts. Hosted on GitHub Pages.
